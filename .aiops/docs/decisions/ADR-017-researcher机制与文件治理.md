# ADR-017：researcher 机制改造 + 文件治理（8 项拍板全落地 + 净增记账）

- 日期 / 所处阶段：2026-09-04 / 大需求收尾（批次6 终验）
- 决策内容：按《需求书-researcher机制与文件治理.md》落地 8 项拍板——① 多宿主通用（去 `.qoder/` 硬编码）② 调研者对齐特例，问答经主控逐字转发，无直连例外 ③ 联网为 grill 技能安装硬前提（来源写死 mattpocock/skills 钉死 commit 3cca18b3，双指纹核对）④ MIT 许可（运行时下载不构成再分发，须署名）⑤ 临时件不计预算、先入库留证再删 ⑥ 需求登记子集入库留证后随下一 commit 必删（pre-commit D 判据三态机械拦）⑦ 回填机械门禁（⑤栏先占位 `待交付回填`，整批 PASS 才回填，终验 PASS 仍待回填 = FAIL）⑧ 净减尺子落"删旧抵消 + 记账"例外句（本 ADR 即记账载体）。
- 为什么（白话，写给不懂编程的项目所有者）：以前 AI 干活时验收结论散成一堆小文件、对齐需求时 AI 可能绕过中间人直接找您问、问完的方法没有门槛容易走样、干完活文档越堆越多没人管。这次改造后：验收结论记进一本"台账"（每件事追加一节，不再一份一个文件）；对齐时 AI 之间传话必须逐字转发，不许添油加醋；拷问方法从网上固定地址下载、装完核对指纹，防止走样或被换皮；文件数量、位置、临时件存活期全部由 git 钩子机械拦，不靠自觉。
- 放弃的备选方案及原因：① 允许调研者直连项目所有者提高对齐效率——否决：破坏"唯一发言人"铁律，传话失真无处追责；② 预算检查做成手动脚本由主控自觉跑——否决：需求 5 判据本身的判据 = 钩子级才算落地，手动跑必然漏；③ 验收结论继续"每批一个 check-<批次> 文件"——否决：文件爆炸根因之一，台账制一份记完。
- 边界条件（白话）：① 预算 C 判据（根目录只许 AGENTS.md/README.md）对本仓库存量治理件（主控卡/放权机制/智能体角色定义/需求书/实施指导书）豁免——白名单机制服务新项目，不含本仓库存量，首次触红登记豁免不倒查；② 预算 E 判据对老项目存量 check-* 文件豁免（只拦新增），历史项目首次触红归档一次；③ 无网/内网环境 install-grill-skill.sh 三通道全失败=红，此时由 AI 网页抓取逐字落盘后指纹自检兜底；④ 例外条款不得连续两次——下一次机制修订必须净减。
- 已知失败模式（白话）：① 钩子只防"忘写/漏交"不防"伪造"——台账存在、已 staged、含同字 PASS/FAIL 即放行；伪造的防线 = checker 只认磁盘 + 异源；② check-grill-skill.sh 指纹只防内容被改，不防"整份换皮"（换皮 = 指纹不同 = 红，天然拦截）；③ 预算钩子只数"位置与数量"不判内容——单文件超大归 check-lean.sh 字节尺子管；④ raw/jsdelivr 备通道在本机网络不可达，仅 api.github.com 主通道实测可达，其他网络环境未实测。
- 影响的文件：主控卡.md、智能体角色定义.md、README.md、项目模板/.aiops/scripts/hooks/{pre-commit,README.md,check-files-budget.sh,check-grill-skill.sh,install-grill-skill.sh}、项目模板/.aiops/docs/PROGRESS.md.template、项目模板/.aiops/docs/archive/归档件模板/{审计报告模板,PLAYBOOK}.md.template、项目模板/.aiops/读集.md.template、项目模板/说明-如何使用本项目模板.md、项目模板/.aiops/AGENTS.md.template

## 补充说明

- 回填门禁：需求登记⑤栏对齐阶段一律留占位 `待交付回填 | 关联批次=<批号 | 未定>`；对应功能/批次整批 PASS 并 commit 时才回填（commit 号 + 台账节路径），不许提前填（填了就是编造）；终验时关联批次已 PASS 而⑤仍待回填 = 终验 FAIL（角色定义终验职责 J 项）。
- 沙箱实测结论（批次1/2，/tmp/gk-sandbox，测完即弃）：install 双技能下载+指纹绿；grilling 缺失/篡改=硬红；预算 A 项 11>10 拦、复原绿；中文名散落文件 quotepath 红测过；audits 台账前缀双向测过；PROGRESS 220 行硬红；台账缺节拦/PASS-FAIL 不符拦；子集三态（入库放行/未删拦/删除放行）全过。
- 执行期发现的指导书外修复（均经沙箱复验）：① budget 脚本 mode 参数解析与 `mode=xxx` 调用约定不兼容（`mode=diff` 被当裸值比对失败，pre-commit 内置调用时 D 判据恒红），已修为兼容两种传法；② PROGRESS 模板已完成区示例行残留旧 `check-B3-0822.md` 命名（5.1 漏改），被终验 #1 拦截后修复为 `ledger-日常.md`。
